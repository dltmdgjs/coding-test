# DP - 동적 계획법
- [이전 문제의 답을 저장해두고 그 답으로 현제 문제의 답을 만든다.]

- 큰 문제를 작은 문제로 나누고, 작은 문제의 답을 저장해두었다가 다시 써서 빠르게 푸는 방법

- 가장 중요한 건, dp 배열을 어떻게 정의하느냐 이다.
  즉, 점화식을 잘 생각해야 한다.

## 예시 : 피보나치 수열
- f(n) = f(n-1) + f(n-2)

## 보통 다음의 순서로 생각한다.
1. dp[i]가 무엇인지 정의 한다.
2. 현재 답을 이전 답들로 어떻게 만들지 찾는다. (점화식 세우기)
3. 초기값을 정한다.
4. 작은 문제부터 순서대로 계산한다. (반복문 이용)

## 이전 6주차에 보았던 LIS(DP)를 생각해보라
1. 그 떄 우리는 dp[i]를 "i번째 원소를 마지막으로 하는 LIS의 길이."로 정의 했다.
2. 그리고 점화식을 세울 때, 이전 값인 dp[j]를 이용하여 dp[i] = max(dp[i], dp[j]+1)이라는 점화식을 세웠다.
3. 초기값은 1로 설정하였다.
4. 반복문을 이용해 첫 원소부터 순차적으로 구해 나갔다.


## 아래는 다양한 dp[i] 정의 예시들임. (코드 작성 전 이것을 먼저 작성하자.)
- 최소 비용 문제 → dp[i] = i까지 가는 최소 비용
- 최대 점수 문제 → dp[i] = i까지 얻을 수 있는 최대 점수
- 경우의 수 문제 → dp[i] = i까지 가는 방법의 수
- LIS → dp[i] = i에서 끝나는 가장 긴 증가 수열의 길이


## 문제를 풀어 나가는 방식 2가지
1. Bottom-Up : 작은 문제에서 큰 문제 (보통 많이 보는 형태)
2. Top-Down : 큰 문제에서 필요한 작은 문제, 메모이제이션 방식이라고 불림, 재귀 사용


## 하지만, 점화식을 바로 세우는 것은 어렵다.
- 그래서 다음과 같은 순서로 해결하자.
1. '완전탐색'을 풀듯 어떠한 idx에서 모든 경우의 수를 생각하고,
2. 그 경우의 수를 '메모이제이션'한다. (계산된 값을 저장해 다시 계산하는 것을 방지)


## DP 경우의 수
- 경우의 수를 풀때, DP를 사용하는 경우 '그냥 다 더한다'고 생각하면 된다.
